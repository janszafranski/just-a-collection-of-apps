just a… WEBcreator

A desktop website designer for Linux. Lay pages out freely, put the header and the menu on a master page so every page shares them, preview in your browser, and publish plain HTML to a folder you can upload anywhere.

It is a ground-up recreation of the easy end of a desktop web designer: menus where you expect them, a toolbar, a page in front of you, and a Site tree down the side. If you have used one of the ARTcraft apps to lay out a page, nothing here should need learning. The powerful, complicated half — the parts most people never open — is not here on purpose.

What it does

New siteFrom any of 92 templates, or empty, through the Startup Assistant
PagesAdd, delete, reorder, nest — the Site tab draws the tree to whatever depth it has
Master pagesCreate, edit and assign per page, so headers and menus are written once
ObjectsText, pictures, shapes, buttons, navigation bars, tables, forms, embedded HTML — drag, resize, rotate, align
PublishPlain HTML and CSS into a folder, with your own filenames. No build step, nothing to host but files
OpensIts own .webc sites, a website folder, and a Serif WebPlus .wpp publication — read-only on your original

Install

sudo pacman -S --needed pyside6 python-beautifulsoup4 qt6-webengine
git clone https://github.com/janszafranski/just-a-collection-of-apps.git
just-a-collection-of-apps/apps/webcreator/install.sh

Only pyside6 is required, and use the distro package rather than pip or the app will not pick up your desktop theme. python-beautifulsoup4 is for importing a website folder; qt6-webengine makes an import match the original layout.

92 templates

Pick one on the left, pick a colour scheme, untick any pages you don't want, and open it. Eighty-nine of these follow the page trees of the templates Serif WebPlus X8 shipped — the page names, the filenames each page publishes as, which page hangs off which, and the colour schemes that template was drawn in, read off the install disc.

The pictures below are not Serif's. No artwork, copy or code of theirs is used or redistributed here. Every picture on this page is the home page WEBcreator itself builds from that template, drawn by the app in its own procedural artwork, in that template's first colour scheme. The structure is the part that was worth recreating; the drawing is ours.
