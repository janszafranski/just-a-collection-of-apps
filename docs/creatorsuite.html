just a… CREATORsuite

The home for the whole family: a two-pane hub with your apps on the left and everything you have made on the right — a Recent list and a browser of your “just a…” folders, so you can jump straight back into a project.

What it does

  • Launch any app, or filter the file list to one app
  • Recent files across every app, newest first
  • Import older files you saved before the shared folders existed
  • Updates each app from GitHub, and installs ones you don't have yet
  • One place for everything you make

Install CREATORsuite

Install the dependencies for your distribution, then clone and run the installer. Nothing needs root except the dependency line.

Arch / CachyOS / Manjaro:

sudo pacman -S --needed pyside6

Then, on any distribution:

git clone https://github.com/janszafranski/just-a-collection-of-apps.git
just-a-collection-of-apps/apps/collectionofapps/install.sh

Only PySide6 is strictly required — use your distribution's package, not pip, so the app follows your desktop theme. The installer checks the rest and tells you what, if anything, is missing. There is an uninstall.sh beside it.
