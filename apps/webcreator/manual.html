1. Overview

WEBcreator is a visual website designer. You lay out pages by dragging objects onto them — text, pictures, navigation, forms and more — share headers and footers on master pages, and publish plain, fast HTML to a folder you can upload to any host.

It is the web companion to just a… PAGEdesigner (print documents) and can open Serif WebPlus .wpp publications and import existing website folders.

2. Installing & launching

WEBcreator needs PySide6 (your distribution's package, e.g. sudo pacman -S --needed pyside6). Install it from the just a… CREATORsuite launcher, or run webcreator. Sites are saved as .webc files.

3. Getting started — the Startup Assistant

On launch the Startup Assistant offers three ways in: a design template, a new blank site, or open an existing one. You can also open a Serif WebPlus .wpp file or import a website folder.

Starting blank, you choose a page width and whether the site should be responsive (scale to fit phones and tablets). Templates come with several ready-made pages and a colour scheme you can swap.

4. Pages & master pages

A site is a set of pages shown in the Site panel. A top-level page can have sub-pages that nest under it and appear in drop-down navigation automatically.

A master page carries anything shared across pages — the logo, the navigation bar, the footer — so you edit them once. Set a page's master, name, file name and background in Page Properties.

6. Text & images

Drag the Text tool to make a frame and type; text wraps inside. Use the Format menu for bold, italics, alignment, lists and hyperlinks. Import Text… brings in text from a file. Pictures can cover, contain or stretch to their frame, and you can crop them.

7. Fills — solid, gradient & transparency

Shapes, text frames, pictures and buttons can be filled. Select one, then use the context toolbar's Fill colour, or the Fill-type button (▣) for a solid colour, a linear gradient, a radial (circular) gradient, or no fill. Gradients publish as CSS gradients; object transparency is set from the Transparency panel.

8. Audio

The Audio tool places a player. Double-click it to choose a sound file (embedded in the site) or paste a link, and give it a title. It publishes as a standard HTML audio player with the browser's own controls.

9. Embeds — comments, forms & more

Insert ▸ Embed adds a third-party service as an HTML fragment — the static-site way to do things WebPlus called "smart objects":

  • Comments (Disqus) — enter your Disqus shortname.
  • Mailing list (Mailchimp) — paste your signup form's action URL.
  • Form (Google Forms) — paste the form's share URL.
  • Custom embed / iframe — paste any HTML.

Combined with the built-in Form object and the News Feed (a blog), this covers most dynamic needs without a server.

10. News Feed & RSS

The News Feed object lists the sub-pages of the page it sits on as story cards, newest first — a built-in blog. Insert ▸ News from a Link fetches an article's web address and turns it into a story page automatically. Publishing also writes an RSS feed and a news.json index so readers can subscribe.

11. Importing existing sites

File ▸ Open WebPlus Site… reads a Serif WebPlus .wpp publication — pages, master pages, text, pictures and navigation — as an editable site. Import a Website Folder brings in an existing site (including Google Sites downloads).

12. Responsive & SEO

Turn on Responsive so the whole design scales to fit narrow screens — phones and tablets reflow to the chosen breakpoints. Fill in SEO titles, descriptions and a focus keyword per page (and a base web address site-wide) so search engines and social cards show your pages well.

13. Previewing & publishing

Preview opens your site in a browser, or in the in-app Website / Phone / Tablet window so you can check the responsive layout. Publish writes the whole site as plain HTML into a folder you choose — ready to upload to any web host (or push to GitHub Pages / Netlify).

14. Companion apps

Toolbar buttons jump to the family: Edit in PAINTcanvas opens the image editor (just a… PAINTcanvas), and the Documents button opens just a… PAGEdesigner for print documents and PDFs. Not-installed apps point you to the CREATORsuite launcher.

16. Shapes, effects & line styles

Beyond the rectangle and ellipse, the shape tools include a QuickShapes gallery — stars, arrows, speech bubbles, hearts, polygons and more. Pick one from Insert ▸ QuickShapes, or re-shape any selected box from the shape drop-down on the context toolbar. They publish as crisp inline SVG.

Any object can take a drop shadow or outer glow — the Effects… button on the context toolbar, or right-click ▸ Effects. They preview live and publish as CSS filters.

Lines and the borders of shapes can be solid, dashed or dotted, and lines can carry arrowheads on either or both ends — all from the context toolbar.

17. More text tools

New text features in the Format menu and context toolbar:

  • Drop cap — a large first letter for a paragraph (the ¶ toggle on a text frame's toolbar); the published page wraps the text around a true floated capital.
  • Check Spelling (F7, or Format ▸ Check Spelling) — lists misspellings with suggestions, and an Add to Dictionary for your own words.
  • Convert to Table — right-click a text frame to turn tab-, comma- or space-separated lines into a table.
  • Transform… — type an object's exact position, size and rotation.

18. Editing pictures

Right-click a picture (or use the Edit in PAINTcanvas button on the toolbar / Assets panel) to open it in just a… PAINTcanvas, the image editor. Save there with Ctrl+S and the picture updates here automatically.

For quick fixes without leaving WEBcreator, the right-click Adjust Picture menu applies Auto Contrast, Greyscale, Sepia, Invert, brightness / contrast / saturation, Sharpen or Blur straight to the image.
