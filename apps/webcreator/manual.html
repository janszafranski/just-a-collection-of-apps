Chapter 1

Getting Started

WEBcreator is a page-layout program in the tradition of Serif’s WebPlus. You place text, pictures, shapes and tables on a page exactly where you want them, then preview in a browser and publish plain HTML you can upload anywhere. This chapter introduces the workspace and the everyday jobs of opening, saving and viewing a publication.

Starting the program

Launch WEBcreator from the CREATORsuite launcher or by running webcreator. It opens on the Startup Assistant, where you choose how to begin.

Starting from a template

WEBcreator opens on the Startup Assistant, where you choose a starting point. The quickest way to begin is from one of the 92 built-in templates — complete little sites, each with a page tree, colour schemes and placeholder content you simply replace. Ninety of them follow the page structures Serif’s WebPlus X8 shipped, so if you knew those you will feel at home.

Pick a template on the left, choose a colour scheme, untick any pages you don’t need, and open it. Prefer a clean slate? Start a blank site and build the pages yourself.

Opening and saving

Use File ▸ Open for an existing .webc site, or the Open page of the Startup Assistant for recent work. File ▸ Save (Ctrl+S) stores your site; Save As makes a copy. By default sites are saved to your shared Documents/just a… folder, so the CREATORsuite launcher can find them again.

WEBcreator also opens a Serif WebPlus site: File ▸ Open WebPlus Site… imports a .wpp site as an editable document (your original is never touched), and Import Website Folder… pulls in an existing set of HTML pages.

The workspace

A new document opens with the page in the centre and everything you need around it.

Down the left is the tool palette; along the top, the menu bar and toolbar; to the right, the tabbed panels (Pages, Swatches, Line, Transparency, Transform, Layers and the Colour picker). The rulers frame the page, and the status bar along the bottom shows the current page and zoom.

Moving around and zooming

Change the zoom with the control at the bottom-right, with Ctrl+scroll, or with the Zoom tool. View ▸ Fit Page and Fit Width frame the page quickly. The Pan tool (or holding the space bar) slides the page around when you are zoomed in.

Chapter 2

Setting Up Pages

Every publication is a stack of pages that share a paper size and, usually, a common background. This chapter covers adding and arranging pages, master pages for repeating content, and the guides and rulers that keep a layout tidy.

Pages and the Pages tab

The Pages tab lists every page in the document. Use the buttons beneath it to add a page, delete the current one, or move a page up or down the running order. Double-click a page to go to it.

Master pages

Anything that should appear on every page — a logo, a footer, a page number, a watermark — belongs on a master page. A master sits behind the ordinary pages that use it, so you draw the object once and it shows through everywhere.

Create one with New master page, edit it with Edit master page, and set which master a page uses from Master properties. Built a page already and realised several items repeat? Arrange ▸ Move Repeated Objects to Master Page… lifts them onto the master for you.

Rulers, guides and the grid

Drag out from a ruler to drop a guide line; objects snap to guides as you move them, which makes columns and margins easy to keep even. The ruler’s corner toggles between measurement origins. Turn snapping and the layout grid on or off from the View menu.

Headers, footers and page numbers

Put headers and footers on a master page so they repeat. For automatic page numbers, add a text frame to the master and insert a page-number field — each page then shows its own number without any manual updating.

Chapter 3

Working with Objects

Text frames, pictures, shapes and tables are all objects. Whatever the kind, you select, move, size, arrange and align them in the same way — the skills in this chapter apply everywhere in the program.

Selecting and moving

With the Pointer tool, click an object to select it; Shift-click to add more to the selection, or drag a band across several at once. Drag any selected object to move it; the handles around it resize it, and the round handle above it rotates it.

The Transform panel

For exact control, open the Transform tab and type an object’s position, width, height or rotation angle. This is the reliable way to make two objects the same size, or to place something a precise distance from the page edge.

Aligning and distributing

Arrange ▸ Align lines selected objects up — left edges, centres, right edges, tops or bottoms — either to each other or to the page. Distribute spaces three or more objects evenly. Alignment is what turns a rough arrangement into a crisp one.

Order, grouping and locking

Objects stack in the order you create them. Arrange sends a selection to the front or back, or forward and back one step at a time, so a caption can sit over a picture. Group ties several objects together so they move as one; Lock / Unlock pins something in place so you can’t nudge it by accident.

Chapter 4

Text

Text is the heart of most publications. WEBcreator handles it the WebPlus way — in frames you can link and flow, with artistic text for headlines, and full control over fonts, paragraphs and styles.

Text frames

Choose the Text tool and drag a rectangle to make a text frame. Type into it and the text wraps inside the frame’s edges. A frame is the basic container for body copy.

Flowing and linking frames

When a frame holds more text than it can show, an overflow marker appears. Drag a link from that marker to another frame and the text flows on — exactly how a newspaper runs a story across columns and pages. Resize or delete a frame and the text re-flows through the chain automatically.

Artistic text

Where frame text is for paragraphs, artistic text is a single line you can scale to any size — the tool for mastheads, titles and pull-quotes. It stays crisp at any size because it is vector, not a picture of type.

Fonts, paragraphs and styles

Select text and use the Format menu and the text panel to set the font, size, weight, colour, alignment and line spacing. A drop cap enlarges the first letter of a paragraph into the lines below it; bulleted and numbered lists structure a sequence of points. Running the same look across a document is easier with text styles, so a heading is always the same heading.

Wrapping and checking

Text can wrap around a picture or shape so the two sit together neatly. Before you print, run Format ▸ Check Spelling… (F7); you can also turn a tab-separated block of text into a real table with convert text to a table.

Chapter 5

Navigation, Links and Interactive Parts

A website is more than a single page — it is pages joined by links, with a few interactive pieces a printed document could never have. This chapter covers the parts that make a page a web page.

Navigation bars

A navigation bar is the row of links that lets visitors move around your site. Drop one in with the nav tool; it builds itself from your page tree, so adding a page adds a button, and it updates everywhere at once. Put the nav bar on a master page and every page inherits the same menu.

Buttons and links

Any object can be a link: select it, and point it at another page in your site, a web address, an email or a file to download. A button is a ready-styled link — the “Get a free quote” button on the sample home page — that you can colour to match your design.

Pictures that enlarge, galleries and slideshows

A gallery cycles through a set of photos as a slideshow, and a lightbox picture opens full-size when a visitor clicks it — ideal for a portfolio. Both are objects you drop on the page and fill with images.

Forms, search and embedded media

A contact form lets visitors send you a message; a search box helps them find a page; and you can embed a YouTube or Vimeo video, a map or an audio clip straight into the layout. A news feed keeps a running list of updates.

Tables

Websites use tables too. Insert ▸ Table drops a grid you type straight into — a price list or an opening-hours panel — with its own header row and adjustable columns.

Chapter 6

Pictures

Pictures bring a page to life. WEBcreator keeps them in frames you can crop and style, and hands off to PAINTcanvas when a photo needs real editing.

Picture frames

Choose the Picture tool and drag a box to create a picture frame. A new frame shows a placeholder until you give it an image; double-click it to choose a photo. Keeping pictures in frames means you can design the layout first and drop the photographs in later.

Fitting, cropping and borders

A picture fits its frame — filling it or sitting inside it — and you can crop to show just the part you want. Round the frame’s corners or give it an outline from the Line panel to finish it off.

Editing a photo

Need to brighten, retouch or cut out a photo? Edit in PAINTcanvas sends the picture across to the image editor; when you save there, the edited version comes straight back into your page.

Chapter 7

Shapes, Lines and QuickShapes

Shapes and lines structure a page and add visual interest — a coloured band for a masthead, a rule between stories, a star on a special offer. WEBcreator’s QuickShapes give you twenty ready outlines, each with a fill, an outline and optional effects.

Drawing shapes and lines

The shape tools draw rectangles (with optional rounded corners), ellipses and straight lines. Hold a modifier while dragging to constrain a square or circle. A thin filled rectangle makes a neat rule.

QuickShapes

QuickShapes are ready-made outlines — triangles, diamonds, polygons, stars, arrows, a chevron, a cross, a heart, a lightning bolt, a speech bubble and a cloud. Pick one and drag it out, then resize and recolour it like any other shape.

Fills, outlines, dashes and arrowheads

Every shape has a fill and an outline; lines can be dashed and finished with arrowheads. Set them in the Colour and Line panels — a dashed line with an arrowhead makes a simple callout.

Drop shadow and glow

Filter effects lift an object off the page. A drop shadow adds depth; an outer glow draws the eye to a highlight or a price. Both are adjustable — colour, blur, offset and strength.

Chapter 8

Colour, Fills and Transparency

Colour ties a publication together. WEBcreator offers solid colours, swatches you keep to hand, gradient fills and adjustable transparency.

Applying colour

The Colour picker sets a solid fill or outline for the selected object — choose a colour with the sliders or type a hex value. The Fill, Line and Text tabs at the top of the picker say which part of the object you are colouring.

Swatches

The Swatches tab keeps a palette of colours one click away, so a document stays consistent. Save a colour you use often and reuse it across every object.

Gradients and transparency

Beyond flat colour, a gradient fades one colour into another across a shape, and transparency lets what is behind show through — for a tint over a photo or a soft watermark. Both are set from the panels of the same name.

Chapter 9

Search Engines and SEO

A website is only useful if people can find it. WEBcreator builds search-engine basics into every page so your site reads well to Google and to visitors alike.

Page titles and descriptions

Each page carries a title and a short description — the words a search engine shows in its results. Set them from This Page’s SEO…, and site-wide defaults from Site-wide SEO….

Auto-generated SEO

In a hurry? Auto-generate SEO for all pages… reads each page’s own headings and text and fills in sensible titles and descriptions for the whole site at once — a good starting point you can then refine.

Chapter 10

Preview and Publish

When the site is ready, WEBcreator shows you exactly what a visitor will see, then writes plain HTML you can put online anywhere.

Preview in your browser

Before publishing, Preview opens your site in a real web browser, so you see it exactly as a visitor will — links, nav bar, galleries and all. Run a final Check Spelling… (F7) too.

View the HTML

Curious what the program writes? View HTML shows the code for the current page. You never have to touch it — WEBcreator writes clean, standards-based HTML and CSS for you.

Publish your site

Publish writes your whole site — every page, picture and stylesheet — as ordinary HTML files into a folder on your disk. Upload that folder to any web host, or open it straight from disk. There is no account, no lock-in and no monthly fee: the files are yours.
