1Welcome to DRAWmaster

DRAWmaster is a vector drawing program in the tradition of Serif DrawPlus. You build pictures from shapes, lines and curves that stay razor-sharp at any size, and save them as SVG you can re-open and keep editing.

This Quick Start takes you from a blank canvas to a finished drawing. For the full reference, open Help ▸ User Guide.

2Starting a drawing

DRAWmaster opens on a fresh canvas, ready to draw. Everything you make is vector, so you can resize and recolour it endlessly without it ever going fuzzy.

3The workspace

The toolbox runs down the left; the canvas fills the middle; the options bar along the top sets the current fill, line width and shape.

4Drawing shapes and lines

Drag out a rectangle, an ellipse or a straight line. Each shape has a fill and an outline you can set before or after you draw it.

5QuickShapes

Choose a QuickShape from the Shape list — a star, an arrow, a heart, a speech bubble and sixteen more — and drag it onto the canvas. Resize and recolour it like any other shape.

6The pen and freehand tools

The pen clicks out a polyline point by point; the freehand tool draws a smooth path as you drag. Close a path to make a filled shape of your own.

7Fills and outlines

Give a shape a solid fill and an outline of any colour and width; a line can be dashed. An outline-only shape (no fill) makes a frame.

8Effects

Lift a shape off the page with a drop shadow or an outer glow — both adjustable for colour, blur, offset and strength.

9Selecting and arranging

With the pointer, click to select and drag to move; the handles resize. Order sends shapes in front or behind, and you can group several to move as one.

10Colours

Set the fill and line colours from the colour controls — the same colour you pick is reused until you change it, so a drawing stays consistent.

11Saving as SVG

File ▸ Save writes an SVG. DRAWmaster stores your editable drawing inside the file, so re-opening it brings every shape back exactly as you left it — and the same SVG opens in any web browser.

12Exporting and PAINTcanvas

Export a PNG for a fixed-size picture, or send the drawing to PAINTcanvas with Edit in PAINTcanvas when you want to paint over it.

13Where to go next

That is the whole round trip: new canvas → shapes, QuickShapes, pen and freehand → fills, outlines and effects → arrange → save as SVG. The User Guide covers every tool, and the other apps in the family work the same way.
