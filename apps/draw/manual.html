Part I
Getting Started
Chapter 1

Welcome to DRAWmaster

DRAWmaster is a vector drawing program: a tool for building pictures out of shapes, lines and paths that stay perfectly sharp at any size. It belongs to the just a… family of apps and works in the tradition of Serif's DrawPlus — the same ideas, the same way of drawing.

What vector drawing is

There are two kinds of picture on a computer. A bitmap (or raster) image — a photograph, or anything you paint in PAINTcanvas — is a grid of coloured dots; blow it up and the dots show as fuzzy squares. A vector image is different: it is stored as instructions — “a red star here, a blue line there” — so the computer re-draws it crisply at whatever size you ask. Zoom in a hundred times and the edges stay razor-sharp.

That makes vector drawing the right tool for logos, icons, diagrams, maps, badges and illustrations — anything that must look clean at any size, from a business-card corner to a banner across a wall.

The object model

Everything you draw in DRAWmaster is an object, and there are only a handful of kinds:

  • Rectangles and ellipses — the two basic boxed shapes;
  • QuickShapes — ready-made outlines such as stars, arrows, hearts and speech bubbles;
  • Lines — a single straight segment;
  • Freehand paths — a flowing line you draw by hand, as if with a pencil;
  • Pen polylines — a shape built point by point, which you can leave open or close into a filled outline.

Because they are all objects, the skills are shared: whatever the kind, you select it, move it, give it a fill and an outline, and lift it off the page with a shadow or glow — all in exactly the same way. Learn those moves once and they apply to everything you draw.

The just a… family

DRAWmaster has three companions, and they are built to work together:

  • PAINTcanvas is the raster image editor — DRAWmaster can hand a finished drawing across to it for photo-style touch-ups;
  • PAGEdesigner lays out printed pages — posters, flyers, newsletters;
  • WEBcreator builds websites the same way.

They share the CREATORsuite launcher and a common Documents/just a… folder, so your work is always easy to find. Once you know one app, the others feel familiar.

About this guide

This User Guide is the complete reference. It is organised in parts: the first gets you working, the middle teaches each skill in depth with step-by-step procedures, then come worked projects you can follow start to finish, output and sharing, and finally a reference section — menus, shortcuts, a catalogue of every QuickShape, and a glossary.

NoteThroughout, a numbered “To …” box is a procedure you can follow exactly. A Tip suggests a faster or better way. A Remember box flags something easy to forget.

For a gentler first read, start with the Quick Start Guide (Help ▸ Quick Start Guide), which takes you from a blank canvas to a finished drawing in a dozen short steps.

Conventions used here

A few conventions keep the instructions short:

  • Menu ▸ Command means “open this menu and choose this command”, e.g. File ▸ Save as SVG….
  • Keys are shown like Ctrl+S; on a Mac read Ctrl as Cmd.
  • Click means the left mouse button; drag means press, move, release; double-click finishes a pen shape.
Chapter 2

Starting Out

This chapter covers the very first things: launching the program, the canvas you draw on, and starting a new drawing at the size you want.

Launching the program

Open just a… DRAWmaster from the CREATORsuite launcher, from your system's application menu, or by running draw in a terminal. It opens straight onto a blank white canvas, ready to draw.

Starting a new drawing

DRAWmaster opens with a default canvas, but you can start fresh at a chosen size at any time.

To start a new drawing

  1. Choose File ▸ New… (Ctrl+N).
  2. Pick a canvas size from the list — a general 1000 × 700, an A4 page (794 × 1123), full-HD 1920 × 1080, or a square 800 × 800.
  3. Click Create. The canvas clears to the new size, ready for your first shape.
NoteThe canvas size sets the drawing’s coordinate space and the proportions of an exported PNG. Because the drawing is vector, you can still scale the result up or down afterwards without losing sharpness.

Saving and opening

DRAWmaster saves your work as an SVG file — the standard vector format, readable by browsers, other drawing programs and the web.

To save your drawing

  1. Choose File ▸ Save as SVG… (Ctrl+S).
  2. Give it a name. It is saved into your shared Documents/just a… folder by default, so the launcher can find it.
  3. DRAWmaster quietly tucks the full, editable drawing inside the SVG, so it can re-open its own files with every shape intact.

To open a drawing

  1. Choose File ▸ Open SVG… (Ctrl+O) and pick an .svg file.
  2. A drawing DRAWmaster saved itself opens fully editable.
RememberDRAWmaster can re-open the SVGs it saved with every object editable, because it stores its object list inside the file. A plain SVG made by another program still displays as a picture elsewhere, but DRAWmaster cannot break it back into editable shapes.
Chapter 3

The Workspace

Everything you do happens in the workspace: your canvas in the middle, the drawing tools down the left, the style controls across the top, and a status bar below. This chapter names every part so the rest of the guide can refer to them.

A tour of the window

A new drawing opens with the white canvas centred on a grey pasteboard and everything you need arranged around it.

The parts are:

  • the menu bar across the top — File, Edit and Help;
  • the Style toolbar below it — fill, line, width, QuickShape, effects and zoom;
  • the vertical tool palette down the left edge;
  • the canvas itself in the centre;
  • the status bar along the bottom, which shows the pointer's position.

The tool palette

The vertical tool palette on the left holds the tools you draw and edit with. Click one to select it; it stays active until you choose another.

From the top, the tools are the Select pointer, Freehand (a pencil), the Pen (for point-by-point polylines), Line, Rectangle, Ellipse and QuickShape. Each is covered in detail in Part II.

TipChoosing the Select tool is the quickest way to stop drawing and go back to picking things up and moving them.

The Style toolbar

The horizontal Style toolbar along the top sets how the next shape will look — and restyles the selected one.

  • Fill — the colour inside a shape (the button shows the current colour);
  • Line — the colour of the outline;
  • Width — the outline thickness, in pixels (0 for no outline);
  • Shape — which QuickShape the QuickShape tool draws;
  • Effects… — the drop shadow and glow for the selected object;
  • Zoom — zoom in, zoom out, and back to 100%.

Moving around and zooming

You will zoom in to place things precisely and out to judge the whole drawing.

To change the zoom

  1. Click Zoom + or Zoom − on the Style toolbar to step in or out, or
  2. click 100% to return to actual size.

When the drawing is larger than the window, scroll bars appear around the canvas so you can slide to any part of it. The status bar at the bottom shows the pointer's exact position in canvas coordinates — useful for lining a shape up precisely.

Core Skills
Chapter 4

Drawing Shapes

Rectangles, ellipses and QuickShapes are the building blocks of most drawings. This chapter covers drawing each of them, and the two dozen ready-made QuickShapes.

Rectangles and ellipses

To draw a rectangle or an ellipse

  1. Choose the Rectangle or Ellipse tool from the tool palette.
  2. Press on the canvas where one corner should be, drag to the opposite corner, and release.
  3. The shape appears with the current fill and outline, and is left selected so you can adjust it at once.

Each new shape takes the Fill and Line colours and the Width currently shown on the Style toolbar — so set those first if you know the look you want, or change them afterwards with the shape selected.

QuickShapes

QuickShapes are ready-made outlines — you do not draw their edges by hand, you simply drag out a box and the shape fills it. DRAWmaster has 18 of them.

To draw a QuickShape

  1. On the Style toolbar, pick a shape from the Shape list (choosing one switches to the QuickShape tool automatically).
  2. Drag a box on the canvas; the shape is drawn to fit it.
  3. Resize, recolour or move it afterwards like any other object.

They cover geometry (triangle, right triangle, diamond, pentagon, hexagon, octagon, parallelogram, trapezoid), stars (five- and six-point), arrows (single, double and a chevron), a cross, and the expressive shapes — heart, lightning bolt, speech bubble and cloud — ready for a badge, a diagram or a caption.

Chapter 5

Drawing Lines and Paths

Where shapes give a drawing its solid forms, lines and paths give it movement and detail — a rule, a connector, a flowing hand-drawn stroke, or a custom outline you build point by point.

Straight lines

To draw a straight line

  1. Choose the Line tool.
  2. Press where the line should start, drag to where it should end, and release.
  3. A line has no fill — only a colour and a width, both set on the Style toolbar.

A line is the simplest object there is: two points, a colour and a thickness. Set the Width high for a bold rule, or to 1 for a hairline.

Freehand drawing

The Freehand tool is a pencil: it records your pointer's path as you drag, giving a natural, hand-drawn stroke.

To draw a freehand stroke

  1. Choose the Freehand tool.
  2. Press and hold, then draw — the line follows your pointer exactly.
  3. Release to finish. The stroke becomes a path object you can recolour, re-weight, move or delete.
TipFreehand is ideal for signatures, sketchy underlines, loose doodles and the organic lines that a perfectly straight tool cannot give you. Zoom in first for finer control.

The Pen: point-by-point polylines

The Pen tool builds a shape one corner at a time — the precise way to draw an exact outline, a polygon, a zig-zag or a many-sided star of your own.

To draw with the Pen

  1. Choose the Pen tool.
  2. Click once for each corner; a line follows your pointer so you can see the next segment before you place it.
  3. To finish as a closed, filled shape, double-click — the outline joins up and fills with the current fill colour.
  4. To finish as an open line instead, press Enter — the points stay joined but the shape is not closed and not filled.
NoteA closed pen shape behaves like any other filled object — it takes a fill, an outline and effects. An open pen line behaves like a multi-segment line. Choose which you want by how you finish: double-click to close, Enter to leave open.
Chapter 6

Selecting and Moving Objects

Once something is on the canvas you will want to pick it up, move it, and get rid of mistakes. Those moves all start with the Select tool.

Selecting an object

To select an object

  1. Choose the Select tool (the pointer at the top of the palette).
  2. Click an object. A dashed blue box appears around it to show it is selected.
  3. Click a different object to select that one instead, or click empty canvas to deselect.
NoteClicking picks the topmost object under the pointer — the one drawn most recently. To reach something behind it, move the object on top out of the way first.

Moving an object

With the Select tool, press on a selected object and drag it to a new place; release to drop it. The whole object moves together, keeping its size, colour and any effects. The status bar shows the pointer's position as you go, so you can line something up against a coordinate.

Deleting an object

To delete an object

  1. Select it with the Select tool.
  2. Press Delete (or Backspace). The object is removed.
  3. Changed your mind? Edit ▸ Undo (Ctrl+Z) brings it straight back.
Chapter 7

Fill, Line and Width

Every shape in DRAWmaster has two coats of colour — a fill inside and an outline around — plus an outline width. Those three controls, all on the Style toolbar, carry most of a drawing's style.

Setting the fill colour

To set a fill colour

  1. Click the Fill button on the Style toolbar.
  2. Pick a colour in the colour dialog — drag in the wheel, type a hex value, or set the alpha (opacity) slider for a see-through fill.
  3. Click OK. If an object is selected, its fill changes at once; otherwise the colour waits for the next shape you draw.
NoteThe Fill button is tinted with the current fill colour, so you can always see what the next shape will be filled with.

Setting the line colour

To set a line (outline) colour

  1. Click the Line button on the Style toolbar.
  2. Pick a colour and click OK.

The outline sits around the edge of a shape (or is the whole of a line or an open pen path). A dark, thin outline makes a shape crisp; a thick, contrasting one makes it bold.

Setting the outline width

The Width spin box on the Style toolbar sets the outline thickness in pixels.

To change the outline width

  1. Select the object (or set the width before drawing).
  2. Type a number in the Width box, or click its up/down arrows.
  3. A width of 0 removes the outline entirely — useful for a shape that should be a pure block of colour.
TipA shape with a bold fill and no outline (width 0) reads as a clean, modern block; a shape with no fill and a thick outline reads as a frame or a ring. The three ways — fill only, outline only, both — are shown together below.
Chapter 8

Effects: Shadow and Glow

Two filter effects lift an object off the flat canvas: a drop shadow that casts it forward, and an outer glow that haloes it. Both are set in one dialog and can be used together.

Adding a drop shadow

To add a drop shadow

  1. Select the object with the Select tool.
  2. Click Effects… on the Style toolbar.
  3. Tick Enable drop shadow.
  4. Set the offset across and offset down (how far the shadow is thrown), the blur (how soft it is), the strength (how dark), and a colour.
  5. Click OK.

A soft shadow a little down and to the right is the classic way to make a shape look as if it floats a few millimetres above the page.

Adding an outer glow

To add an outer glow

  1. Select the object and open Effects….
  2. Tick Enable outer glow.
  3. Set the spread (how far the glow reaches) and the strength (how strong), and a colour.
  4. Click OK.

A glow in a bright, warm colour draws the eye to a highlight; a soft white glow lifts a shape off a dark background. An object can carry a shadow and a glow at the same time — tick both.

Removing an effect

To take an effect off again, open Effects… and untick the box for the shadow or the glow, then click OK. The effect is removed; the object itself is untouched.

Chapter 9

Undo, Redo and Working Safely

Drawing is a process of trying things. DRAWmaster keeps a deep history of your changes, so you can experiment freely and step back whenever something does not work.

Undo and redo

Nearly everything you do — drawing a shape, moving it, recolouring it, adding an effect, deleting something — is recorded.

To step back and forward through your work

  1. Choose Edit ▸ Undo (Ctrl+Z) to reverse the last change.
  2. Keep pressing to walk back through the history, step by step.
  3. Choose Edit ▸ Redo (Ctrl+Shift+Z) to re-apply a change you undid.
NoteThe history holds many steps, so you can undo a whole run of changes — not just the most recent one. Starting a fresh change, though, clears the “redo” branch from that point on.

A safe way to work

Because Undo is deep and reliable, the best way to learn DRAWmaster is to try things. Draw a shape, recolour it, pile on a shadow and a glow, drag it about — and if you do not like the result, undo back to where you were. Save often (Ctrl+S) once a drawing is going well, so you always have a known-good version to return to.

Chapter 10

Project: A Simple Logo

This project builds the badge-style logo you have seen in this guide, from an empty canvas to a finished mark — putting the skills of Part II to work in order: QuickShapes, fills and outlines, and effects.

Start with a backing shape

To lay the foundation

  1. Choose File ▸ New… and a square 800 × 800 canvas — logos suit a square.
  2. Pick a deep colour on the Fill button and a darker one on Line, with a wide Width.
  3. From the Shape list choose Octagon and drag out a large backing shape.
  4. Open Effects… and give it a soft drop shadow so it lifts off the page.

Add the central symbol

Now place the mark the logo is built around — here, a star.

To add the central symbol

  1. Set a bright Fill (a warm gold) and a matching Line.
  2. Choose the Star (5-point) QuickShape and drag it out, centred on the octagon.
  3. Open Effects… and add a gentle outer glow in a pale version of the fill, so the star seems to shine.

Finish with supporting shapes

A few supporting shapes round the logo out — a heart and a speech bubble here, each in its own colour.

To add the finishing shapes

  1. Draw a Heart QuickShape in a strong accent colour.
  2. Draw a Speech bubble with a white fill and a coloured outline.
  3. Nudge each into place with the Select tool until the arrangement feels balanced.

Export and reuse

With the logo finished, save it and export it for use elsewhere.

To save and export the logo

  1. Choose File ▸ Save as SVG… so you can re-open and edit it later.
  2. Choose File ▸ Export PNG… for a ready-to-use bitmap — to drop into a document, a website or an email.
TipKeep the SVG as your master. If the brand colour ever changes, re-open it, recolour the shapes and re-export — no quality is ever lost, because it is vector.
Chapter 11

Project: An Icon and a Diagram

Two more short projects show the range of a vector tool: a clean app-style icon, and a simple flow diagram built from shapes and arrows.

A clean icon

An icon is a logo stripped to its simplest: one strong shape, one clear symbol, no clutter.

To draw a flat icon

  1. Start from a square canvas.
  2. Draw a Rectangle that fills most of the canvas, with a bold fill and no outline (Width 0) — the rounded modern look.
  3. Draw one simple symbol on top — a QuickShape such as a Lightning bolt, Heart or Star — in white or a contrasting colour.
  4. Export a PNG at the size you need it.
RememberAn icon is read at a tiny size. Resist adding detail that will vanish when it is 32 pixels wide — one shape and one symbol is usually plenty.

A flow diagram

Vector shapes and arrows make a tidy diagram that you can always rearrange.

To build a flow diagram

  1. Draw a row of Rectangles (or ellipses) for the steps, all the same fill.
  2. Between each pair, draw an Arrow QuickShape, or a Line, pointing from one to the next.
  3. Use the Pen tool for a branch that bends around a corner.
  4. Keep the fills to two or three colours so the diagram reads calmly.
TipBecause every box and arrow is a separate object, you can drag a step to a new place and redraw just the arrows around it — far quicker than redrawing the whole diagram.

Chapter 12

Exporting and Sharing

A finished drawing is meant to be used — on a web page, in a document, in an email, or touched up as a photo. DRAWmaster exports to the two formats that cover all of those.

Saving an editable SVG

SVG is DRAWmaster's own save format — a vector file that stays editable.

To save as SVG

  1. Choose File ▸ Save as SVG… (Ctrl+S).
  2. Name it and save. The drawing goes to your Documents/just a… folder by default.
NoteA DRAWmaster SVG is a genuine, standard SVG — a browser or another vector program will display it. DRAWmaster also tucks its full editable object list inside, so it can re-open the file with every shape intact. Edit a DRAWmaster SVG in another program and that editable copy may no longer match, so keep DRAWmaster’s SVG as your master.

Exporting a PNG

A PNG is a bitmap — the right format when you need a fixed-size picture to drop into a document, a website, a chat or an email, where SVG might not be accepted.

To export a PNG

  1. Choose File ▸ Export PNG….
  2. Name it and save. It is written at the canvas’s pixel size, on a white background, into your Pictures/just a… folder by default.
TipNeed the PNG bigger and still crisp? Start a larger canvas (or scale the whole drawing up) before exporting — because the drawing is vector, a larger export is just as sharp, unlike enlarging a PNG after the fact.

Touching up in PAINTcanvas

When a finished drawing needs raster-style work — a textured background, a photographic blend, a filter — DRAWmaster hands it to its sister app.

To edit a drawing in PAINTcanvas

  1. Choose File ▸ Edit in PAINTcanvas….
  2. DRAWmaster rasterises the drawing to a PNG and opens it in PAINTcanvas.
  3. Do your pixel-level work there and save.
RememberThis is a one-way trip: a drawing becomes a bitmap when it crosses to PAINTcanvas, and a bitmap cannot be broken back into editable vector shapes. Keep your SVG master so you can always go back to the editable version.

Chapter 16

Appendix D — Glossary

The drawing words used in this guide.

A–Z

Alpha
The opacity of a colour — a low alpha makes a fill partly see-through.
Bitmap (raster)
A picture made of a grid of coloured dots, such as a PNG or a photo; it blurs when enlarged.
Drop shadow
A soft, offset copy behind an object that makes it look raised off the page.
Fill
The colour inside a shape.
Freehand
A path drawn by hand, following the pointer like a pencil.
Object
Anything you draw — a shape, a line or a path; each is selected and styled on its own.
Outer glow
A soft halo of colour around an object.
Outline (line / stroke)
The coloured edge around a shape, or the body of a line.
Path
A freehand stroke, stored as the series of points it followed.
Pen / polyline
A shape built point by point; closed and filled, or left as an open line.
PNG
A common bitmap image format; DRAWmaster exports to it for fixed-size pictures.
QuickShape
A ready-made shape outline (star, arrow, heart, speech bubble…).
SVG
Scalable Vector Graphics — DRAWmaster’s editable save format, and a web standard.
Vector
Artwork defined by maths, not pixels — sharp at any size.
Width
The thickness of an outline, in pixels; 0 means no outline.
Chapter 17

Appendix E — Troubleshooting

Quick answers to common snags.

Common questions

My shape has no outline.
The Width is set to 0, or the Line colour is unset. Raise the width and pick a line colour on the Style toolbar.
My shape has no fill — it is hollow.
Lines and open pen paths never fill. For a shape, click the Fill button and pick a colour; a filled object draws solid.
I can’t select the object I want.
Clicking picks the topmost object. Move the one on top aside, or delete it, to reach what is behind.
My pen shape won’t fill.
You pressed Enter, which finishes an open line. Finish with a double-click to close and fill the shape instead.
I opened an SVG and couldn’t edit its shapes.
That SVG was made by another program. DRAWmaster can re-open with full editing only the SVGs it saved itself.
My effect vanished when I exported a PNG.
It should not — shadows and glows are drawn into the export. If a glow looks faint, raise its strength, then export again.
