User Guide

A tiny vector drawing app — shapes, lines and paths saved as an infinitely scalable SVG.

The workspace

Tools on the left; fill, line colour and width on top.

Drawing

Pick a tool and drag: Rectangle, Ellipse or Line. Freehand draws as you drag; Pen clicks points then double-click (or Enter) to finish a polyline. New shapes use the current fill and line.

Selecting & editing

The Select tool picks a shape (dashed outline), drag to move it, Delete to remove it. With a shape selected, change its fill, line colour and width from the top toolbar.

Saving

File ▸ Save as SVG… writes a scalable vector file; Export PNG… writes a bitmap. Ctrl+Z undoes.
