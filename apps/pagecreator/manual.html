1. Overview

PAGEdesigner is a desktop publishing (DTP) application for making printed documents: flyers, newsletters, booklets, business cards, posters and more. You place text, pictures and shapes freely on fixed-size pages, arrange them exactly where you want, and export a print-ready PDF or print directly.

It is the print companion to just a… WEBcreator (which makes websites) and can open Serif PagePlus .ppp publications so your older work comes forward. This guide covers every part of the program, from the first page to a finished PDF.

How a document is built

  • Pages have a true physical size (A4, A5, a business card…). What you see is what prints.
  • Objects — text frames, pictures, shapes, tables — sit on the pages at exact positions.
  • Master pages hold anything that should repeat on every page (a header, a footer, page numbers).
  • Export produces a vector PDF, so text stays crisp at any size; or you print straight to a printer.

2. Installing & launching

PAGEdesigner needs PySide6 (install it with your distribution's package, e.g. sudo pacman -S --needed pyside6 on Arch/CachyOS). Install the app from the just a… COLLECTION of apps launcher — its Install button downloads the app and sets up a menu entry, a pagecreator command and the .pagc file type.

Launch it from your application menu ("just a… PAGEdesigner") or by running pagecreator in a terminal. Open a file directly with pagecreator mydoc.pagc or pagecreator design.ppp.

3. Getting started — the Startup Assistant

Each time PAGEdesigner opens, the Startup Assistant appears. It is the launch pad for a new or existing document.

Starting a new publication

Click New Publication, then a paper size. Sizes are grouped the way a print shop thinks of them:

  • Documents — A4, A4 Landscape, A5, A3, US Letter, US Legal.
  • Business — Business Card (85×55 mm), Letterhead, DL Flyer, Postcard, Compliments Slip.
  • Booklet & Folded — A5 and A4 Booklet (multi-page), Greeting Card, Tri-fold Brochure.
  • Large Format — A3, A2 and A1 Posters.

Each card shows the size in millimetres. Clicking one creates a blank document at exactly that size (booklets start with four pages). For anything else, use Custom size and type a width, height and page count in millimetres.

Opening existing work

Switch to Open to re-open a recent document, Browse… for a saved .pagc file, or Open PagePlus… to import a Serif PagePlus .ppp publication (see Opening PagePlus files).

Untick Show this when PAGEdesigner opens to skip the assistant in future; you can still reach everything from the File menu.

4. The workspace

The main window has four main areas.

  • The page fills the centre, shown at true size against a grey pasteboard. Scroll and zoom to move around (Ctrl+scroll to zoom, or View ▸ Zoom).
  • The tool rail (left) holds the drawing tools — Pointer, Artistic Text, Text Frame, Table, Picture, Rectangle, Ellipse, Line, Rotate and Crop.
  • The context toolbar (top) changes to show the properties of whatever you have selected — font and size for text, Fill and Line for shapes, and so on.
  • The Pages panel (right) lists the document's pages and master pages.

The menu bar carries File, Edit, View, Insert, Format, Arrange, Export PDF and Help. Companion-app buttons (Edit in PAINTcanvas, WEBcreator) sit on a toolbar for jumping between the "just a…" apps.

5. Documents & pages

Document Setup

File ▸ Document Setup… sets the page size and orientation for the whole document. Pick a preset (A4, A5, A3, Letter, Legal) or type a custom width and height in millimetres, choose Portrait or Landscape, and set the margin guide (a non-printing guide inset from the edge). Canvas pixels are 1/96 inch, so the millimetre size you choose is the exact physical size that prints.

Adding and arranging pages

Use Insert ▸ Page… (or the Pages panel) to add a page; drag pages in the panel to reorder them. Delete a page from the panel or the Pages toolbar.

Page properties

Right-click a page (or Format ▸ Page Properties) to set its name, its master page, a custom page height (leave on "Document default" to match the document), and a background colour.

6. Master pages & page numbers

A master page is a template layer shared by the pages that use it — ideal for a running header, footer or logo. Edit a master from the Pages panel; anything you place there appears on every page assigned that master. Assign a page's master in Page Properties.

Automatic page numbers

  1. Choose Insert ▸ Page Number Field. A small frame showing # is placed.
  2. Move it where you want the number, then cut/paste it onto a master page.
  3. Every page that uses that master now shows its own page number automatically.

7. Working with objects

Everything on a page is an object. With the Pointer tool:

  • Select by clicking; Shift-click to add to the selection; drag a band over empty space to select several.
  • Move by dragging; resize with the corner/edge handles; rotate with the round handle above a selected object (or the Rotate tool).
  • Align several objects with Arrange ▸ Align (left edges, centres, etc.).
  • Order overlapping objects with Arrange ▸ Bring to Front / Send to Back.
  • Lock an object (Arrange ▸ Lock) so it can't be moved by accident.

8. Text frames

Drag the Text Frame tool to draw a frame, then type. Text wraps inside the frame. A small red ▾ marker appears in the bottom-right if there is more text than fits — enlarge the frame, shrink the text, or link it to another frame so the overflow flows on.

Double-click a frame to edit its text; use the Format menu (or the context toolbar) for bold, italics, underline, alignment and lists. Artistic Text (a separate tool) is single-line text you can scale freely — good for headlines and logos.

9. Linked text frames (text flow)

Linked frames let one story run across several frames — the heart of newsletter and magazine layout.

  1. Create two or more text frames.
  2. Select them in the order the text should flow (click the first, Shift-click the rest).
  3. Right-click ▸ Link Text Frames.

Now type (or paste) into the first frame — when it fills, the text continues in the next linked frame, and the next, like columns in a newspaper. Editing any linked frame edits the one shared story. Right-click ▸ Unlink Text Frames to separate them again.

10. Text styles & formatting

Format ▸ Text Styles applies a ready-made look to the selected text frame:

BodyNormal paragraph text
CaptionSmall italic text under pictures

Styles set the frame's font, size, weight and colour in one click, so a document stays consistent.

11. Wrapping text around objects

To make text flow around a picture or shape:

  1. Place the picture/shape over (or beside) a text frame.
  2. Right-click it ▸ Wrap Text Around This.

The text in any frame it overlaps now flows around the object — above it, down the free side, and below it. Right-click ▸ Stop Wrapping Text to turn it off. A small gap is left automatically so text never touches the object.

12. Pictures & cropping

The Picture tool places an image frame; choose a file to fill it. A picture can be set to cover the frame (fill and crop), contain it (fit inside), or stretch. Use the Crop tool to drag out just the part of a picture you want to keep. Round a picture's corners from the context toolbar.

13. Shapes, lines & QuickShapes

Rectangle and Ellipse draw filled shapes (hold Shift for a perfect square or circle); Line draws a straight line. Set the fill and the outline (line colour and width) from the context toolbar, and round a rectangle's corners with the Corners control.

14. Fills — solid, gradient & transparency

Any shape, text frame, picture frame or button can be filled. Select it, then on the context toolbar use the Fill colour swatch for a flat colour, or the Fill-type button (the ▣ icon beside it) for:

  • Solid colour… — pick a flat fill colour.
  • Linear gradient… — a smooth blend between two colours along an angle you choose.
  • Radial (circular) gradient… — a blend radiating out from the centre.
  • No fill — make the object transparent (outline only).

Gradients are also on the right-click menu (Linear / Radial Gradient Fill…, Remove Gradient). Object transparency (opacity) is set from the Transparency panel. Gradients and transparency export faithfully to PDF.

15. Guides, columns, grid & crosshair

Guides help you line things up; none of them print.

  • View ▸ Guides & Columns… divides the page into columns and rows (with a gutter) inside the margin — the classic layout grid.
  • The faint dashed margin guide shows the page margin (set in Document Setup).
  • View ▸ Crosshair adds full-width and full-height guide lines that follow the pointer.
  • View ▸ Grid and Snap to Grid give a dotted grid objects snap to; Rulers run along the top and left.

16. Booklet view

Turn on View ▸ Booklet View to see the whole document as facing-page spreads — the cover alone on the right, then pages 2–3, 4–5 and so on — exactly how a reader will hold it. It is a read-only overview; double-click any page to leave booklet view and edit that page.

17. Tables

The Table tool places a grid of cells. Double-click a table to edit its cells; set fonts, colours and borders from the context toolbar. Tables are useful for price lists, schedules and data.

18. Placing PDFs

Insert ▸ Place PDF… drops a page of another PDF onto your page as a picture (rendered at high resolution). Useful for reusing a supplied advert, a logo sheet or a page from another document.

19. Opening PagePlus (.ppp) files

File ▸ Open PagePlus… reads a Serif PagePlus .ppp publication (PagePlus X3 and later) and rebuilds it as an editable PAGEdesigner document — text, pictures, shapes, colours and the page size all come across.

If a picture in the original was linked (stored outside the file) rather than embedded, it can't be brought across; the import summary tells you how many. Very old pre-X3 PagePlus files are a different, unreadable format.

20. Printing

File ▸ Print… (Ctrl+P) opens your system print dialog and prints the document to a printer, rendered at the printer's resolution so text and shapes are sharp. Each document page becomes one printed page at its true size.

21. Exporting PDF — bleed & crop marks

Export PDF (Ctrl+E) writes a vector PDF: text stays selectable text and shapes stay vectors, so it is crisp at any size. The export dialog offers two professional-print options:

  • Bleed — extends the page by a few millimetres so artwork that runs to the edge has no white sliver after trimming. Design objects slightly past the page edge to use it.
  • Crop marks — thin corner marks showing a print shop exactly where to trim.

With no bleed and no marks, you get a plain PDF at the document's exact size.

22. Preflight check

File ▸ Preflight Check scans the document before you print or export and lists likely problems:

  • Objects that extend past the page edge (fine if you meant to bleed).
  • Picture frames with no image.
  • Pictures that are low-resolution at their placed size (under ~150 dpi; 300 dpi is ideal for print).
  • Text frames with hidden overflow.

A clean report means the document is ready to go.

23. Companion apps

The toolbar's companion buttons jump to the other "just a…" apps: Edit in PAINTcanvas opens the image editor (just a… PAINTcanvas), and WEBcreator opens the website designer. If an app isn't installed yet, you'll be pointed to the COLLECTION launcher to install it.
