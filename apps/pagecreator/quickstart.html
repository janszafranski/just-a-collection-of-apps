1Welcome to PAGEdesigner

PAGEdesigner is a desktop-publishing program: you lay a page out by placing text, pictures, shapes and tables exactly where you want them, then print it or export a PDF. It works the way Serif's PagePlus did — the same menus, in the same places.

This Quick Start takes you from a blank page to a finished, printable newsletter in a dozen short steps. For the complete reference — every feature, worked projects and a full menu guide — open the User Guide (Help ▸ User Guide).

2Start a publication

When PAGEdesigner opens it shows the Startup Assistant. Choose Start from a design to build on a ready-made template, or New Publication for a blank paper size — A4, a card, a booklet or a poster.

3The workspace

Your page sits in the middle, the tools down the left, the menus and toolbars across the top, and the panels on the right.

4Start from a template

The quickest route to a finished piece is Start from a design. Pick a layout, then make it your own — change the words, swap the photo, recolour anything.

5Add text

Drag out a text frame and type; the text wraps inside it. For a headline or masthead, use Artistic text — a single line you scale freely. A frame that overflows can flow into a second, linked frame.

6Add pictures

Draw a picture frame with the Picture tool, then double-click it to drop in a photo. Crop it or round its corners; for real edits, Edit in PAINTcanvas sends it across and brings the result back.

7Shapes and QuickShapes

Draw rectangles, ellipses and QuickShapes — stars, arrows, speech bubbles and more. Each has a fill and an outline, and can carry a drop shadow or glow.

8Tables, charts and QR codes

Insert ▸ Table drops a grid you type into; Insert ▸ Chart… turns figures into a bar, line or pie chart; Insert ▸ QR Code… makes a scannable code for a flyer.

9Arrange and align

With the Pointer, click to select, drag to move, pull the handles to resize. Arrange ▸ Align lines objects up; Transform sets exact positions; Lock stops accidental nudges.

10Colour and transparency

The Colour panel sets a fill, line or text colour; Swatches keeps favourites handy. Add a gradient fill, or make something transparent so what's behind shows through.

11Add finishing touches from the Asset library

Insert ▸ Asset… drops in ready-made callouts, badges, banners and decorations — a SALE burst, a ribbon, an arrow. Everything stays editable: recolour it, retype the words.

12Check, then print or export

Run Check Spelling… (F7) and a quick Preflight. Then Export PDF… (Ctrl+E) for a crisp vector PDF, or File ▸ Print to send it to your printer.

13Where to go next

That is the whole round trip: new page → text, pictures, shapes and tables → arrange → export. The User Guide covers every feature in depth, with worked projects and a full reference. And the other just a… apps work the same way — once you know one, you know them all.
