Bundled fonts — just a... PAGEdesigner
======================================

These are display, script and slab typefaces that ship with the app and appear in
the font pickers and the Fonts panel. They are the same open-licence faces Serif's
packages bundled (sourced here from a Serif package's own font folder), all of which
are freely redistributable:

  * SIL Open Font License 1.1 (OFL): Alegreya Sans SC, Alex Brush, Amatic SC,
    Arvo, Berkshire Swash, Bowlby One SC, Carrois Gothic SC, Chewy, Cinzel,
    Finger Paint, Flamenco, Fredericka the Great, Glegoo, Henny Penny,
    Julius Sans One, Lobster, Monoton, Nixie One, Pacifico, Patrick Hand SC,
    Racing Sans One, Sue Ellen Francisco.
  * Apache License 2.0: Just Another Hand, Permanent Marker, Rock Salt,
    Special Elite.

Each font remains under its own licence; the licences travel with the font files.
Commercial (non-redistributable) faces from the same Serif packages are deliberately
NOT included here.
