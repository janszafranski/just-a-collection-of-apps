Bundled fonts — just a... PAGEdesigner
======================================

A library of display, poster, serif, script and slab typefaces that ship with the
app. They appear in every font picker and in the Fonts panel (each shown as a large
sample), and travel with the app so they work even on a machine that doesn't have
them installed.

All are freely redistributable open-licence faces:

  * SIL Open Font License 1.1 (OFL) — the great majority, including:
    Alegreya Sans SC, Alex Brush, Amatic SC, Anton, Arvo, Abril Fatface,
    Archivo Black, Alfa Slab One, Bangers, Bebas Neue, Berkshire Swash, Bitter,
    Bowlby One SC, Bungee, Carrois Gothic SC, Caveat, Chewy, Cinzel,
    Cinzel Decorative, Comfortaa, Cormorant, Courgette, Dancing Script,
    DM Serif Display, Finger Paint, Fjalla One, Flamenco, Fredericka the Great,
    Fredoka, Glegoo, Great Vibes, Henny Penny, Josefin/Julius Sans One,
    Kaushan Script, Lato, Lobster, Lobster Two, Monoton, Montserrat, Nixie One,
    Nunito, Oswald, Pacifico, Passion One, Patrick Hand SC, Playfair Display,
    Poppins, Racing Sans One, Raleway, Righteous, Sacramento, Staatliches,
    Sue Ellen Francisco, Teko, Work Sans, Yeseva One, Zilla Slab.

  * Apache License 2.0: Just Another Hand, Permanent Marker, Roboto Slab,
    Rock Salt, Special Elite.

Sources: the open-licence faces Serif's own packages bundled, plus a curated set
downloaded from the official Google Fonts project (github.com/google/fonts). Each
font remains under its own licence, which travels with the font file. Commercial
(non-redistributable) faces are deliberately NOT included.
