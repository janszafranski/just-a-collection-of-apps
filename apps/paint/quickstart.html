Quick Start

Edit a picture in six steps.

1

Make or open an image

Use File ▸ New (pick a size, or a transparent background for a logo) or File ▸ Open. You can also right-click a picture in WEBcreator/PAGEdesigner and choose Edit in PAINTcanvas.

2

Pick a tool and a colour

Choose a tool on the left rail, set the Colour and Size at the top, and paint. Try the Brush, the Gradient, or the Clone tool (Ctrl-click to set a source).

3

Work in layers

Add a layer with the ＋ button in the Layers panel so you can paint without touching what's underneath. Set its opacity and blend mode, and drag layers to reorder.

4

Improve the photo

Open the Adjust menu for Brightness/Contrast, Levels or Hue/Saturation (the sliders preview live), or the Filter menu to sharpen or blur. Select an area first to change just part of the picture.

5

Retouch & finish

Use Clone, Red-eye, Dodge and Burn for touch-ups, then Image ▸ Crop / Straighten to frame it.

6

Save

Press Ctrl+S to save a PNG or JPG. It lands in your ~/Pictures/just a… folder and appears in the COLLECTION hub.

That's the loop: open → layers → adjust → retouch → save. See the full User Guide (Help menu) for every tool, adjustment and filter.
