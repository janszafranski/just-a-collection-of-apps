User Guide

A tiny raster image editor — paint, draw shapes, fill, add text, and save a PNG or JPG.

Getting started

Choose File ▸ New… to start a blank image (pick a size preset and a background colour), or File ▸ Open… to edit an existing picture. From PAGEcreator or WEBcreator, the Edit in PAINT button opens the app.

The tools

ToolWhat it does
BrushPaint freehand in the current colour and size
EraserRub pixels back to transparent
Line / Rectangle / EllipseDrag to draw a straight line or an outlined shape
FillFlood-fill a connected area with the current colour
Pick colourClick the image to set the colour from a pixel
TextClick, type, and the text is drawn at that point

Colour, size & zoom

Click the Colour button to choose a colour; set the brush Size with the spin box. Use Zoom +/− and 100% to magnify. The status bar shows the pixel under the pointer.

Undo & saving

Ctrl+Z undoes, Ctrl+Y redoes. Save/Save As… writes a PNG (keeps transparency) or JPG (flattened on white).
