User Guide

A tiny raster image editor — paint, draw shapes, fill, add text, and save a PNG or JPG.

The workspace

Tools on the left; colour, brush size and zoom on top; the pixel position shows in the status bar.

Getting started

File ▸ New… starts a blank image (size preset + background), or Open… edits a picture. The Edit in PAINTcanvas button in PAGEdesigner/WEBcreator opens it too.

Tools

ToolDoes

Colour, size, zoom & saving

Click Colour to choose; set Size; zoom with the buttons. Ctrl+Z undoes. Save/Save As… writes PNG (keeps transparency) or JPG.
